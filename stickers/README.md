# Обезьян — стикеры для Telegram

![preview](preview.jpg)

15 статичных стикеров, уже подготовленных под требования Telegram
(прозрачный фон, 512 px по длинной стороне, файл < 512 КБ).

| Папка | Что внутри |
|---|---|
| `webp/` | готовые стикеры WEBP — для бота `upload.py` |
| `png/` | те же стикеры в PNG 512 px — для загрузки через @Stickers |
| `source/` | исходники |
| `stickers.json` | порядок и эмодзи для каждого стикера |

## Способ 1 — вручную через @Stickers (без кода)

1. Откройте [@Stickers](https://t.me/Stickers) → `/newpack` (тип — обычные/статичные).
2. Введите название набора.
3. По очереди отправляйте файлы из `png/` **как файл** (не как фото) и после каждого — эмодзи из таблицы ниже.
4. `/publish` → (иконку можно пропустить `/skip`) → короткое имя для ссылки `t.me/addstickers/<имя>`.

## Способ 2 — одной командой через своего бота

```bash
pip install requests
export BOT_TOKEN=...      # от @BotFather
export TG_USER_ID=...     # ваш id, например от @userinfobot
python3 upload.py monkey "Обезьян"
```

Перед запуском напишите своему боту `/start`. Скрипт выведет ссылку на набор.
Набор будет принадлежать вам (`TG_USER_ID`), управлять им можно через @Stickers.
