# Навык Алисы с YandexGPT

Голосовой помощник для Яндекс Станции: вы говорите «Алиса, запусти навык …», задаёте вопросы голосом,
а отвечает YandexGPT. Навык помнит 3 последние реплики разговора.

Код: [`index.py`](index.py), одна функция без внешних библиотек.

## 1. Yandex Cloud: каталог и оплата

1. Зайдите на **console.yandex.cloud** под тем же аккаунтом Яндекса, что и на Станции.
2. Создайте **платёжный аккаунт** (российская карта). Новым пользователям обычно дают стартовый грант.
3. Откройте каталог (по умолчанию `default`) и скопируйте его **ID**. Он вида `b1g...` и показан рядом с названием каталога.

## 2. Сервисный аккаунт

1. В каталоге: **Identity and Access Management → Сервисные аккаунты → Создать**.
2. Имя, например `alice-gpt`. Роль: **`ai.languageModels.user`**.
3. Сохраните.

## 3. Функция

1. **Cloud Functions → Создать функцию**, имя `alice-gpt`.
2. Среда выполнения **Python 3.12**, способ — **редактор кода**. Создайте файл `index.py` и вставьте содержимое [`index.py`](index.py).
3. Параметры версии:
   - **Точка входа:** `index.handler`
   - **Таймаут:** `5` секунд
   - **Память:** `128 МБ`
   - **Сервисный аккаунт:** `alice-gpt`
   - **Переменные окружения:**
     - `FOLDER_ID` = ID каталога из шага 1
     - `MODEL` = `yandexgpt-lite` (быстрее, рекомендуется) или `yandexgpt` (умнее, но может не успевать за 3 секунды)
4. Нажмите **Сохранить изменения** и дождитесь, пока создастся версия.
5. Проверьте на вкладке **Тестирование**. Вставьте вход:
   ```json
   {"version":"1.0","session":{"new":false},"request":{"command":"сколько варить гречку","original_utterance":"сколько варить гречку"}}
   ```
   В ответе должен быть текст от YandexGPT. Если вместо этого «Не получилось связаться», откройте **Логи** функции: там будет причина.

## 4. Навык в Яндекс Диалогах

1. Зайдите на **dialogs.yandex.ru/developer → Создать диалог → Навык**.
2. **Название и имя активации:** придумайте фразу из двух слов, которую Алиса не спутает с другими, например «Мой умник». Это слово вы будете говорить Алисе.
3. **Backend:** выберите **«Функция в Яндекс Облаке»** и в списке — `alice-gpt`.
4. **Доступ:** **Приватный** (навык будет только у вас).
5. Заполните обязательные поля: описание, иконку, примеры фраз. Затем **Сохранить**.
6. На вкладке **Тестирование** проверьте навык в браузере.
7. Нажмите **Опубликовать**. Приватные навыки проходят упрощённую проверку, обычно это быстро.

## 5. Использование

На Станции, привязанной к тому же аккаунту:
- «Алиса, запусти навык Мой умник», затем задавайте вопросы. Чтобы выйти, скажите «хватит».
- Или одной фразой: «Алиса, спроси у Мой умник, сколько варить гречку».

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| «Не успела придумать ответ» | Поставьте `MODEL=yandexgpt-lite` или задавайте вопросы короче |
| «Не получилось связаться с YandexGPT» | Логи функции: чаще всего у сервисного аккаунта нет роли `ai.languageModels.user` или неверный `FOLDER_ID` |
| Функции нет в списке в Диалогах | Проверьте, что Диалоги и Cloud открыты под одним аккаунтом Яндекса; если не помогло — в настройках функции включите «Публичная функция» |
| Алиса говорит «навык не отвечает» | Проверьте функцию на вкладке Тестирование в Cloud и посмотрите логи |
